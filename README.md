# Omega Instruments — omegasolarproducts.com

Static marketing and product-catalogue site for Omega Instruments,
manufacturer and trader of solar balance-of-system hardware,
Kathwada–Singarwa Road, Ahmedabad.

**Live:** https://omegasolarproducts.com
**Repository:** https://github.com/instackout/omegasolarproducts

## What is in here

| File                | Purpose |
|---------------------|---------|
| `index.html`        | The entire site — HTML, CSS, JavaScript, WebGL engine and 152 product images in one self-contained file |
| `404.html`          | Copy of `index.html`, so a mistyped path still lands on the site |
| `CNAME`             | Tells GitHub Pages which custom domain serves this repo. **Do not delete.** |
| `.nojekyll`         | Stops GitHub trying to process the site with Jekyll |
| `og-image.png`      | Preview card shown when the link is shared on WhatsApp, LinkedIn or Facebook |
| `favicon.ico`, `icon-*.png`, `apple-touch-icon.png` | Browser tab and home-screen icons |
| `site.webmanifest`  | Lets the site be added to a phone home screen |
| `robots.txt`, `sitemap.xml` | Search-engine instructions |

No build step, no dependencies, no server. Editing `index.html` and
committing publishes the change within about a minute.

## Updating the site

Open `index.html` here on GitHub, click the pencil icon, paste the new
version, and commit. Or delete the file and upload the replacement.

See `DEPLOY.md` for first-time setup and DNS.
